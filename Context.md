# CONTEXT.md — MAISON ÉTOILE

## Descripción
MAISON ÉTOILE es una marca ficticia francesa de moda contemporánea, con una identidad moderna, minimalista y premium.

Proyecto académico colaborativo de 4Geeks Academy desarrollado por tres participantes.

## Objetivo
Crear un prototipo visual de tienda online, responsive, accesible y optimizado para SEO.

## Tecnologías
- HTML5 semántico.
- Tailwind CSS.
- CSS adicional únicamente si es necesario.
- Schema.org.
- Git y GitHub.

No utilizar React, Vue, Next.js ni frameworks adicionales. No implementar pagos reales.

## Páginas obligatorias
1. `index.html` — Inicio.
2. `catalog.html` — Catálogo con filtros y 20 productos de referencia.
3. `product.html` — Detalle de producto.
4. `cart.html` — Carrito con tres productos de ejemplo.
5. `checkout.html` — Formulario de pago en tres pasos.

Las páginas deben estar enlazadas entre sí y compartir navbar y footer.

## Identidad
- Marca: MAISON ÉTOILE.
- Mercado: Francia.
- Idioma de la web: español.
- Estética: elegante, minimalista y premium.

## Equipo
Tres desarrolladores:
- Desarrollador 1 (líder): Home, navbar y footer.
- Desarrollador 2: Catálogo y producto.
- Desarrollador 3: Carrito y checkout.

## Colaboración
- Rama principal: `main`.
- Cada desarrollador utiliza una rama independiente.
- Commits descriptivos y pull requests.
- Revisión de los cambios antes de fusionarlos.

## Documentación
- `AGENTS.md`: instrucciones para asistentes de IA.
- `CONTEXT.md`: contexto y requisitos.
- `DESIGN.md`: identidad visual.
- `docs/`: documentación y referencias compartidas.
- `specs/`: especificaciones, tareas y planes de desarrollo.

## Entrega
Cinco páginas HTML interconectadas, código en GitHub, URL pública y captura de PageSpeed Insights.

Objetivo de rendimiento: al menos 80 puntos, preferiblemente más de 90.
