# AGENTS.md — MAISON ÉTOILE

## 1. Instrucciones generales

Este proyecto académico se desarrolla en equipo utilizando asistentes de inteligencia artificial.

Antes de comenzar cualquier tarea, el asistente debe leer:

- `CONTEXT.md`
- `AGENTS.md`
- `DESIGN.md`
- Las especificaciones correspondientes dentro de `specs/`, cuando existan.

Si falta algún documento, debe indicarlo.

## 2. Tecnologías

Utilizar exclusivamente:

- HTML5 semántico.
- Tailwind CSS.
- CSS adicional cuando sea necesario.
- Schema.org para datos estructurados.

No utilizar React, Vue, Next.js, Angular ni otros frameworks.

No implementar backend, bases de datos ni pagos reales.

## 3. Reglas de desarrollo

- Mantener el contenido de la tienda en español.
- Aplicar diseño mobile-first.
- Garantizar compatibilidad con móvil, tablet y escritorio.
- Seguir las decisiones visuales de `DESIGN.md`.
- Utilizar HTML accesible y optimizado para SEO.
- Mantener una estructura sencilla y organizada.
- Reutilizar los patrones compartidos de navbar, footer y tarjetas.
- No añadir funcionalidades fuera de los requisitos aprobados.

## 4. Trabajo colaborativo

El proyecto tiene tres desarrolladores, cada uno con responsabilidades asignadas.

El asistente debe:

- Respetar los archivos de otros participantes.
- No modificar funcionalidades ajenas sin autorización.
- No trabajar directamente sobre `main`.
- Proponer cambios pequeños y fáciles de revisar.
- No ejecutar commits, push o merges sin autorización.
- Facilitar el trabajo mediante pull requests.

## 5. Procedimiento de trabajo

Para cada tarea:

1. Revisar el contexto, diseño y especificaciones.
2. Explicar brevemente el plan de implementación.
3. Identificar los archivos que se modificarán.
4. Esperar aprobación.
5. Implementar únicamente lo aprobado.
6. Verificar el resultado.
7. Resumir los cambios realizados.

## 6. Comunicación

- Todas las explicaciones y prompts deben estar en español.
- La interfaz pública de MAISON ÉTOILE estará en español.
- Mantener respuestas claras, breves y orientadas a la tarea.

## 7. Prioridades

En caso de conflicto, seguir este orden:

1. Requisitos del profesor.
2. `CONTEXT.md`.
3. `DESIGN.md`.
4. Especificaciones aprobadas en `specs/`.
5. `AGENTS.md`.

Si existen contradicciones importantes, solicitar aclaración antes de modificar código.
